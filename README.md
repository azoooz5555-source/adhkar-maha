# أذكار وقرآن

إهداء إلى الوالدة مها التركي.

موقع بسيط فيه أذكار الصباح والمساء مع عدّاد، وكتاب حصن المسلم كاملاً، والقرآن الكريم كاملاً مع التلاوة.

- نص المصحف: [مشروع تنزيل](https://tanzil.net) (رخصة CC BY 3.0، منقول حرفياً)
- حصن المسلم: سعيد بن علي بن وهف القحطاني (النص من [hisn_almuslim_json](https://github.com/rn0x/hisn_almuslim_json))
- التلاوة وتوقيت الآيات: الشيخ مشاري العفاسي والشيخ محمد صديق المنشاوي والشيخ عبدالباسط عبدالصمد (mp3quran.net)
